## 1. The Gap
- **Smallholder Farmers:** No collateral = No credit. No data = Low farmgate prices.
- **Institutional Buyers:** No verification = High risk. No direct access = Inefficient sourcing.

## 2. The Solution: YPS + CRP
- **YPS (Yield Probability Score):** Verified soil intelligence replacing traditional collateral.
- **CRP (Community Resource Platform):** A verified marketplace matching farmers with premium buyers.

## 3. How it Works (USSD *165#)
1. **Soil Signals:** IoT nodes monitor 7 biological signals (N, P, K, Moisture, etc).
2. **YPS Score:** Real-time productivity verification on any feature phone.
3. **CRP Access:** Verified farmers list harvests for direct institutional sourcing.
4. **Trusted Trade:** Hash-chained ledger records every listing and settlement.
